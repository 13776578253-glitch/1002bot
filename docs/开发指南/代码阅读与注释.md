# 代码阅读与注释

模块头、架构职责和执行路径范围使用英文，作为结构边界。接口、字段与关键分支的审查说明使用简短中文 JSDoc 或行内注释，说明默认值、单位、边界和顺序原因。名称和类型已经明确的信息不逐行复述。

这种写法参考本地 Cortico：`src/core/core.ts` 用英文模块头定义组合根职责，`src/core/session.ts` 在方法上说明写入和监听边界，`src/core/bus.ts` 在字段与重入分支旁解释状态含义和操作顺序。参考的是注释组织方式，当前项目的保证以自身实现为准。

2026-10-08 已再次核对现有生产源码。新增注释集中在公共契约、内部状态含义和跨异步边界的原因；已有充分说明的字段与分支保留。受理与最终结果、心跳未结算名额、generation/lease/取消、工具已取得回执与保存结果分别说明，不在普通语句旁重复类型和赋值。

| 阅读入口 | 重点 |
| --- | --- |
| `packages/shared/control-api/src/index.ts`、`src/control/index.ts` | 前端与核心共用的控制契约、公开能力与装配导出 |
| `src/protocol/index.ts`、`input.ts`、`trigger.ts` | 跨层契约、三种触发、受理与执行结果、World sink、心跳源、公开诊断与容量 |
| `src/runtime/compose.ts`、`runtime.ts` | 注入依赖、来源订阅、生命周期代次、停止写入屏障；handleEvent 适配统一队列 |
| `src/runtime/input-channel.ts` | UserInput 门面，转换通用回执与快照，不拥有队列 |
| `src/runtime/trigger-channel.ts` | 单消费者、接收追加、外部去重、心跳跳过、取消和终态确认、有限诊断 |
| `src/runtime/trigger-run.ts` | 三种触发共用的模型/工具续轮、时限、unknown 与中断收束 |
| `src/agent/conversation-agent.ts` | 按完整轮次选择上下文、当前轮保留、软余量与硬容量 |
| `src/providers/openai-responses-provider.ts`、`scripted-provider.ts` | 原生输出重放、实际请求体测量、响应限额与离线脚本边界 |
| `src/state/jsonl-session.ts`、`memory-state.ts` | 串行追加、失败链、存储保证与内存值所有权 |
| `src/console/terminal.ts` | 本地命令、文本提交、EOF 与显式退出的收束方式 |
| `packages/apps/tui/src/terminal.ts` | 公开回执与草稿版本、重绘背压、退出等待与终端恢复 |
| `packages/apps/tui/src/input.ts`、`editor.ts`、`text.ts` | 字节分块、粘贴边界、字素、原文索引与显示列宽 |
| `packages/apps/tui/src/state.ts`、`view.ts` | 有限诊断保留、缺口提示、回看锚点、窗口折行与视图焦点 |

当前 M3 已迁移旧 Event 执行循环，所有触发共享 FIFO 与终态规则。JSONL 没有 fsync、多记录事务或自动损坏恢复；abort 不能撤销已经产生的外部效果。M3 自验与验收状态分别见 [阶段报告](../2026-10-08-M3.0进度与架构图.md)，M2 历史验收保留。
