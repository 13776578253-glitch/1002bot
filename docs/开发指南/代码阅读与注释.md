# 代码阅读与注释

模块头、架构职责和执行路径范围使用英文，作为结构边界。接口、字段与关键分支的审查说明使用简短中文 JSDoc 或行内注释，说明默认值、单位、边界和顺序原因。名称和类型已经明确的信息不逐行复述。

这种写法参考本地 Cortico：`src/core/core.ts` 用英文模块头定义组合根职责，`src/core/session.ts` 在方法上说明写入和监听边界，`src/core/bus.ts` 在字段与重入分支旁解释状态含义和操作顺序。参考的是注释组织方式，当前项目的保证以自身实现为准。

2026-10-08 已再次核对现有生产源码。新增注释集中在公共契约、内部状态含义和跨异步边界的原因；已有充分说明的字段与分支保留。受理与最终结果、心跳未结算名额、generation/lease/取消、工具已取得回执与保存结果分别说明，不在普通语句旁重复类型和赋值。

2026-10-13 对 M6 受控响应再作复核：英文模块头锚定 Runtime 的原操作所有权、Agent 的证据查询和独立归档边界；中文注释集中在可信能力、控制目标、UTF-8 JSON 容量、迟到回执语义、必要记录确认与停止重试。非注释语法 token 和去注释 JavaScript 与实施基线一致，注释不改变执行逻辑。
