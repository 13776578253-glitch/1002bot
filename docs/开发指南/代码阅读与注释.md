# 代码阅读与注释

模块头、架构职责和执行路径范围使用英文，作为结构边界。接口、字段与关键分支的审查说明使用简短中文 JSDoc 或行内注释，说明默认值、单位、边界和顺序原因。名称和类型已经明确的信息不逐行复述。

这种写法参考本地 Cortico：`src/core/core.ts` 用英文模块头定义组合根职责，`src/core/session.ts` 在方法上说明写入和监听边界，`src/core/bus.ts` 在字段与重入分支旁解释状态含义和操作顺序。参考的是注释组织方式，当前项目的保证以自身实现为准。

| 阅读入口 | 重点 |
| --- | --- |
| `src/protocol/index.ts`、`input.ts` | 跨层契约、受理与执行结果、公开诊断、容量和保留窗口 |
| `src/runtime/compose.ts`、`runtime.ts` | 注入依赖、生命周期、代次失效、停止写入屏障；兼容 Event 入口与通用输入分开 |
| `src/runtime/input-channel.ts` | 单消费者、受理去重、排队取消、最终记录确认与诊断缓存 |
| `src/runtime/input-run.ts` | 单轮调用期限、工具回执配对、unknown 的停止要求与中断收束 |
| `src/agent/conversation-agent.ts` | 按完整轮次选择上下文、当前轮保留、软余量与硬容量 |
| `src/providers/openai-responses-provider.ts`、`scripted-provider.ts` | 原生输出重放、实际请求体测量、响应限额与离线脚本边界 |
| `src/state/jsonl-session.ts`、`memory-state.ts` | 串行追加、失败链、存储保证与内存值所有权 |
| `src/console/terminal.ts` | 本地命令、文本提交、EOF 与显式退出的收束方式 |
| `src/console/tui/terminal.ts` | 公开回执与草稿版本、重绘背压、退出等待与终端恢复 |
| `src/console/tui/input.ts`、`editor.ts`、`text.ts` | 字节分块、粘贴边界、字素、原文索引与显示列宽 |
| `src/console/tui/state.ts`、`view.ts` | 有限诊断保留、缺口提示、回看锚点、窗口折行与视图焦点 |

注释不扩大运行保证：旧 Event 路径不具备通用输入的 FIFO 与逐输入终态；JSONL 没有 fsync、多记录事务或自动损坏恢复；abort 不能撤销已经产生的外部效果。注释补充未改变 M2 验收状态。
