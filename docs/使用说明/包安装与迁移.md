# 包安装与迁移

核心保留在根包与 src，TUI 位于 packages/apps/tui，轻量公共契约位于 packages/shared/control-api。examples/tui 和 tests/integration 是开发组合与跨包验证工作区，不属于核心或 TUI 的运行依赖。

## 源码安装与检查

以下命令从仓库根执行。默认 `pnpm install` 只安装核心及其依赖；按包命令显式选择依赖集合，整套命令覆盖关闭递归安装的配置。

| 范围 | 安装 | 检查与运行 |
| --- | --- | --- |
| 核心 | `pnpm install:core` | `pnpm typecheck:core`、`pnpm test:core`、`pnpm build`、`pnpm sample`、`pnpm dev:console` |
| TUI 与契约 | `pnpm install:tui` | 先 `pnpm --filter @1002bot/control-api build`，再 `pnpm --filter @1002bot/tui typecheck` / `test` / `build`；探针为 `pnpm probe:tui` |
| 完整开发工作区 | `pnpm install:all` | `pnpm test`、`pnpm typecheck`、`pnpm build:all`、`pnpm dev:tui` |

共享锁文件包含各包解析信息，不表示每个包都安装。干净核心目录已验证没有 string-width、TUI 或框架；干净 TUI 源码目录只包含 TUI/契约，没有核心 src，仍可构建、检查并运行 13 项单元测试。

单独运行 TUI 探针不要求核心；离线组合样例需要完整开发工作区。src/console 是内部测试入口，将来可由其他测试替代。

## 独立安装产物

`pnpm build:all` 后，可在根包、packages/shared/control-api 和 packages/apps/tui 分别执行 `pnpm pack`，生成包含 JS 和声明的独立 tarball。当前包未发布到 registry；源码工作区使用 workspace:，打包时转换为实际版本依赖。

安装核心产物需要对应的契约包；安装 TUI 产物需要契约与列宽依赖，均不要求安装另一侧实现。当前未发布契约时，消费者可通过本地 tarball overrides 指定其来源。完整离线验证命令为 `pnpm check:packages`，自定义缓存位置可追加 `--store-dir <目录>`；此脚本只使用已缓存依赖，不访问网络。

脚本在全新临时目录检查按包源码安装、构建和类型检查，并安装真实 tarball。核心产物使用真实 FixtureWorld/JSONL 与脚本 Provider 完成写入/读回；TUI 产物检查公开运行导出、声明及探针命令。结果保留在 scratch/package-install-check.json。

## 入口与旧路径

| 原入口 | 当前入口 |
| --- | --- |
| src/console/tui | packages/apps/tui/src |
| ConsoleRuntime 的接口定义 | @1002bot/control-api 的 RuntimeControl；内部 Console 保留类型别名 |
| 读取核心内部控制类型 | 共享契约包；核心使用 1002bot/control 导出已有装配能力 |
| scripts/tui-sample.ts | examples/tui/sample.ts，根 `pnpm dev:tui` 命令保留 |
| scripts/tui-probe.ts | packages/apps/tui/src/probe.ts，根 `pnpm probe:tui` 命令保留 |

`runTui` 默认只接受原始 TTY；非 TTY 需由调用方显式提供 `fallback`。组合样例注入内部行式 Console，保持既有换行、提交和 EOF 收束行为；TUI 单包没有对内部测试入口的运行依赖。

packages/apps、extensions、shared 是分类目录，每个实际包独立持有 package.json。WebUI、扩展加载、远程连接与 OpenTUI 均未在本轮实现。
