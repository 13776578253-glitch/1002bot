# Visualization 接手路线

本轮修稳 P0/P1，保留原计划及归档作为历史；本路线按当前审查结果修订实现顺序。

## 本轮

1. 阶段草稿与确认快照独立保存。切回阶段读取本会话最新内容；保存其他阶段不升级未合并修订。首次进入目标阶段读取显式父阶段的确认结果，缺少父阶段确认时阻止并指出所需阶段。
2. 增量安置只处理新对象，确认对象的世界坐标保持。冻结成员新增、删除、归属变动返回冲突。错误保留源布局，候选不写源视口或路径。
3. 冻结账本记录冻结前约束与人工路径，解冻恢复。内部路径与标签使用同一 owner 坐标空间。只允许真实可见端点捕获永久路径，折叠代理边不冒充 Canonical 路径。
4. 锁定路径参与节点移动合法性校验，禁止通过普通路径状态按钮解锁冻结内部路径。确认、展开、定位、分组和拖动均经过同一保护边界。
5. 通过模型回归、类型与构建、原生浏览器的阶段往返及冻结操作后提交。

## 后续

P1 后续：折叠后代的完整内部路由快照、跨边界分段锁定，以及来源修订三方冲突解决。需要逐项行为验收，不能以占位字段或 pinned 状态替代。

P2：在阶段快照之上实现用户覆盖层；先节点/关系增删和重连，再人工拐点、永久路径和原始关系查看。全部变更可撤销并自动恢复，Canonical 来源保持独立。

P3：建立统一路由代价及固定测试图，比较长度、拐弯、交叉、重叠和旧路径扰动；自动端口只搜索自由边。

P4：以 P3 的代价下降为接受条件，对局部自由边执行有界多边重路由，冻结结果逐点不变。
