## 目标与结构

核心继续由根 package.json 与 src 持有；src/console 只作为内部行式测试入口。src/control 集中公开已有控制能力，packages/apps/tui 是独立可选前端包。packages/extensions 与 packages/shared 分别容纳未来独立扩展和有实际分发需求的共享包；不创建没有实现的 WebUI 或扩展空包。

TUI 有独立清单、导出、源码、依赖、类型检查与构建入口。核心单独安装、运行和检查不要求 string-width、OpenTUI、React 或 TUI 所需运行时。组合入口选择核心与前端，同进程直接传入已有能力对象。

## 公共控制边界

将 ConsoleRuntime 的能力形状移出内部行式 Console，以中性公共控制名称导出，复用现有提交、取消、查询、订阅、诊断窗口、等待与生命周期语义。src/control 提供核心公共导出；不为目录变化增加业务执行层。

前端所需契约不通过相对路径读取核心内部源码。若独立打包要求共享类型，将既有前端可见的输入、回执、快照、事件与控制接口收纳到 packages/shared/control-api；核心协议入口保留兼容导出。核心限额、异常实现与执行逻辑仍归核心。不得为了类型包复制两份契约，或提前补齐 World 配置、完整监控、远程协议。

runTui 已解除对内部 runTerminal 的直接依赖。独立 TUI 默认要求原始 TTY，调用方可显式传入 fallback；组合样例注入内部行式入口，重定向回归保持。
