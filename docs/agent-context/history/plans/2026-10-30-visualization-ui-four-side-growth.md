# 架构画布 UI 样式与交互提案

日期：2026-10-29。状态：按负责人浏览器批注修订的候选设计。

## 整体结构

页面由全屏画布、右上角亮暗切换、左下角画布操作组成。阶段导航、顶栏、页面标题、增量工具栏、详情栏和尺寸标注均移除。阶段导航留待负责人后续设计。

多选或选择聚合框时，顶部临时显示相关操作；取消选择后消失。

## 画布与选择

- 空白处拖动平移，滚轮缩放；左下角提供缩放和适应画布。
- 节点可直接拖动，方向键保留 React Flow 的键盘移动能力。
- 点击节点高亮直接相连的入边、出边和邻接节点；点击链路或关系标签高亮该关系与两端节点。
- Shift + 拖动框选，也可点击左下角框选按钮切换模式；Ctrl/Shift + 点击可多选；Esc 清空选择。
- 节点位置变化通过受控 React Flow 状态即时更新，保持画布挂载，连线路径跟随端点。
- 拖动时在距离对齐位置 6 屏幕像素内吸附，按缩放换算画布阈值；显示轻量对齐辅助线，离开阈值后自由移动。跨层卡片按世界坐标对齐。
- 辅助线扣除可见卡片、容器标题和关系标签的占用区，保留 8 px 留白；拖动结束立即清理。
- 相连卡片之间保留至少 64 画布像素净距，为关系标签与箭头留空间；同层对象防止重叠，多选拖动保持相对位置。
- 关系标签优先沿整条路径的可用直段或边界分隔出的子区间放置，必要时贴线侧放，标签边缘距离线段 4 px。标签有不透明底色，图层始终高于边线，选中关系不抬高边线图层。

## 聚合框

- 框选至少两个对象后点击“聚合”，或按 Ctrl/Cmd + G。
- 聚合保持各节点世界坐标；框内节点使用 parentId 与父容器关联。
- 标题直接显示为可编辑输入框，回车或移出焦点提交；通过标题左侧手柄或标题栏空白整体移动分组。
- 子节点可在框内单独移动，边界约束为标题和内边距预留空间。
- 点击“解散”移除框体，子节点保留当前世界坐标。
- 允许将已有聚合框与其他节点再次聚合；选中聚合框时高亮所有内部叶节点关联的链路。
- 拖动任意聚合层级内的卡片，可向上、下、左、右撑开聚合框和结构容器，沿父链扩容。以当前展开组合的自然尺寸为基准，每轴最多增加 100% 且不超过 800 px；相反两侧共享该轴的总余量。整条父链共同约束移动，到任一容器上限后停止向外移动。
- 向左或上扩张时移动容器原点，并补偿直接子项的本地坐标，保持未拖动卡片的世界位置。容器记录自动扩张偏移，使原点与尺寸均可随内容回缩。
- 连续拖动或折叠重开保持同一展开组合的扩容基准。手动扩容按钮与尺寸手柄移除。
- 卡片回拖后，先收缩直接容器，再向外逐层按当前子项边界重算尺寸，保留标题区、左右及底部内边距。自动避让的同层对象在空间恢复后回到原位置；用户主动拖动过的对象保留新位置。缩小后再次外拖仍使用原扩容上限。
- 框选优先保留实际覆盖的后代卡片，取消同时命中的祖先容器；展开层内部卡片可独立参与聚合，新框位于最低共同显示祖先内。
- 新框标题所需留白由父链扩容和坐标重基准获得，保持内部卡片世界坐标，避让被新增边界挤到的邻近节点。解散恢复原显示父层及当前位置，canonical graph 的层级与端点保持原定义。
- 跨层抽出卡片建立新框后，原框按剩余内容重新包围；空手动框清除。新框与同层剩余结构相撞时，移动剩余结构并带动其后代，父链自动包住重新排布后的完整范围。
- 聚合或解散改变成员结构后，以新的自然布局重建受影响容器的扩容基准；日常拖动保持基准固定。外部对象连锁避让保留卡片之间 64 px、容器与其他对象之间 24 px 的间隔。

## 递归层级

- 双击有子项的卡片原位展开为容器；双击容器标题或点击收起按钮返回卡片。
- 会话管理包含消息接收、上下文管理、调度出口；上下文管理包含历史读取和上下文组装；上下文组装包含消息裁剪与摘要合并。
- 展开时父容器按子项边界扩容，沿父链更新尺寸，并错开受影响的同层节点。收起时恢复对应占位尺寸。
- 跨层关系使用 canonical endpoint，展开连接内部节点，收起连接最近可见祖先；容器内部的关系在整体收起时隐藏。
- 连线避开可见卡片与容器标题区，允许穿过容器边界。
- 展开状态、子节点本地位置在收起后保留；移动容器带动内部层级一起移动。
- 界面仅显示节点名称、摘要、子项数量及展开控件，不添加数据来源标识。
