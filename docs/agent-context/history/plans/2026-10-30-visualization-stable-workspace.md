# 稳定布局、自动恢复与折叠连线聚合

## 目标与范围

拆除拖动时的全图重算，新增自由、固定、锁定、冻结布局、自动恢复与事务撤销；报告模块折叠时按可见端点、方向、关系类型聚合外部连线，并支持原始连接查看和端点定位。拖动中保持局部精确避障。手动分组继续保持展开形态。本轮不引入 ELK、Worker、全局布局、命名视图、导入导出、圈画或附着点编辑。

## 工作视图与约束

自由节点可手动和自动移动；固定节点可手动移动、自动布局跳过；锁定节点禁止直接移动和编辑。固定位置使用所属分组相对坐标，整体移动父分组时子节点随动；自动容器原点补偿保持已有世界坐标。锁定不递归修改子级状态；仍可选中、查看与展开折叠。固定和锁定对象都作为障碍物，展开空间不足时原子保持相关布局并提示冲突。多选拖动排除锁定对象，其余保持统一位移。

选择工具栏提供自由/固定/锁定；底部提供冻结当前可见自由节点、撤销、重做。一次操作为事务：拖动包含祖先扩缩与邻居避让，标题一次提交算一步；每阶段最多100步。阶段切换、选择、视口导航不进撤销栈，输入框使用原生撤销。

源架构、可序列化视图和临时交互状态分开。视图保存当前阶段、各阶段节点位置/约束/展开、手动分组与归属、标题、容器尺寸与扩容基准、视口。选择、辅助线、回调、路径缓存和撤销栈不保存。公开 persistence: { key, storage }、CanvasWorkspaceView 与 CanvasViewStorage；Playground 注入 localStorage 适配器。加载先恢复后展示，无记录用初始布局；交互结束及视口结束保存，读写失败明确提示与重试，读取失败不覆盖原记录。版本变更按稳定ID恢复，新节点自由，删除实体和空组移除。阶段切换保留目标几何和约束，同步共同节点展开；冲突项保持目标状态。取消展开和阶段切换自动适应全图。

## 增量几何与渲染

分离拓扑投影、几何缓存与选择高亮。建立节点/父子/邻接/空间索引，拖动不重建拓扑；更新移动根、相关祖先和邻近自由节点，保留吸附、间距、四向扩缩及上限。依据旧/新障碍区域、移动端点、被遮挡路径或标签确定失效边；只对失效边精确寻路，未变化标签为固定障碍。内部相对几何随组移动，外部障碍仍做精确检查。结束仅提交事务与保存。节点/边/回调保持稳定引用，选择和视口不触发寻路，移除分组全量nodes订阅。

## 聚合关系

保留Canonical Graph和原始投影接口，在展示层聚合。关系桶至少一条折叠边且成员多于一条才合并；有向边区分方向，双向边规范化顺序，关系类型独立。内部自折叠边隐藏，单成员保留原标签，完全展开恢复原始ID。保存有序成员、原始端点、标签及变化标记。标签显示数量及新增/替换计数；全新增绿色、全替换琥珀色、混合中性线配文字徽标，沿用不注释。悬浮列表显示端点路径和变化，定位展开祖先并高亮原边、仅聚焦目标；冲突保留布局并提示，展开为一次可撤销事务。

## 实施与验收

依次完成工作视图/约束/事务，增量几何，保存与控件，聚合与定位。覆盖约束保护、事务整体撤销、刷新恢复、分组ID唯一、阶段同步、无关边零重算、非关联遮挡失效、四向扩缩、精确避障、聚合计数/方向/原始ID、变化文字和冲突定位。使用M6浏览器连续拖动记录计算耗时、帧耗时和寻路数量，目标60FPS；重点消除无关全图计算。完成包级/全仓测试、类型检查、库/站点构建与原生浏览器验收。实施记录放current-task，完成后原文归档本计划。
