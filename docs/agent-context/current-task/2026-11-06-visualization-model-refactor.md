# Visualization model 重构

## 实施范围

- 第一批将四条运行时环切断，并将布局、路由、标签、冻结、阶段、工作区和合同归入二级目录。坐标、兄弟避让、可见性、冻结框计算和边界连接各由下层模块提供。内部调用直接迁移，包公开入口保持符号。持久化职责和存储形状留到独立审查。
- 第二批由 `routing/resolve-routes.ts` 统一候选、复用、引擎仲裁、受保护路径恢复和输出的合法性。Legacy 与 Group 的缓存由调用方持有，按原有粒度失效。阶段入口负责把路径失败转换为提交冲突。
- 第三批由 `LabelLayoutCache` 统一标签求解，先迁移有效断言，再删旧求解、占位字段和空标签传递。实际标签位置仍在快照边界捕获。
- 第四批审查节点存储字段、保护状态、派生几何和历史确认，统一确认和继承比较对用户意图的定义，并用已有快照验证恢复。

## 验证

- 以 `7cbe3ff` 的包测试 421 项和两份 TypeScript 检查为基线。分批验证架构约束、包测试、类型检查、分发构建及 Playground 构建。
- 浏览器验证阶段切换、路径引擎降级、标签固定及恢复。使用隔离配置和仓库浏览器会话工具。
