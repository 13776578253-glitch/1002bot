# M2 终端闭环实现

Time: 2026-10-05

Decision: 项目负责人选择“终端 + 受理/事件契约 + 标准容量”。原型中的工作台选择不构成实施决定，以本次明确文本选择为准。

Change: 先接通公共用户输入、FIFO、独立 run 取消、终态与 Session 记录，再实现生产 Agent 的完整轮次上下文和容量测量，最后接入独立 readline Console。首批使用现有 FixtureWorld 的离线样例，首个生产 World 仍另行确定。

Parameters: 请求体 64 KiB，正文 8 KiB，固定内容预留 16 KiB，待执行队列 8，单输入最多模型请求 8 次。Provider 30 秒、工具 10 秒、执行与排队各 120 秒、每批工具最多 8、响应体 1 MiB；沿用 M1 cleanup 默认 100 ms。事件缓存 256 条/4 MiB，快照 128 条/4 MiB，生命周期受理 ID 最多 4096。

Implementation: 保持 M1 事件调用与测试兼容；新增用户输入记录与 run 终态，既有 JSONL 不重写。Runtime 拥有队列和每次运行，Console 仅调用公共契约；Agent 通过 Provider 的公共计量契约选择完整上下文轮次，不依赖具体 World/Console。停止路径写入一次性取消终态并等待全部已提交写入；不确定工具仅诊断，未收束时停止 Runtime，禁止自动重放。

Verification: 真实 JSONL 与 FixtureWorld 加脚本模型验证连续输入、FIFO/队满/重复 ID、取消/停止、迟到结果、时限、unknown、最终文本、存储失败、容量裁剪与 Provider 原始项往返。终端用本地管道验证多行、命令和 EOF；不调用真实模型，不启动真实 bot。执行 pnpm test、pnpm run typecheck、pnpm run sample 与新增离线终端样例。

Open issues: 首个生产 World、独立 Review、真实 Provider 工具往返仍待单独验收。存储永久挂起与不配合取消的 World 保留既有诊断边界。

## 首批实现与验证结果

Time: 2026-10-05

Change: 新增 src/protocol/input.ts、src/runtime/input-channel.ts 与 input-run.ts、src/agent/conversation-agent.ts、src/console/terminal.ts。Runtime 公开 inputs，保留 M1 Event 入口并禁止两类入口同时执行 World；AgentContinuation.input 为 Event | UserInput。标准参数集中定义，单 Session FIFO 与 4096 ID 去重保留跨正常重启状态。

Logic: 每条输入独立 signal 与 runId；受理后立即返回，Provider/工具/执行/排队分别受时限约束。终态由一次性 finalizer 提交，Session 写入完成后发布 run_finished；未完成显示 write_pending，失败为 storage_error/persisted=false。停止屏障等待活动运行、队列终态与已提交写入。工具取消/超时或回执错配保留原 callId 的 unknown，未开始的同批调用 cancelled，自动停止并取消剩余输入；无重放入口。

Context: ConversationAgent 只选取配对完整的成功历史轮次，活动轮次和原始 Provider 输出项整体保留，超限时整轮淘汰；当前轮次仍超限则 context_limit。Provider 无网络计量与 complete 共用序列化方法；Responses 适配器按原始响应体字节数限流解析，并保留 length/error。既有 JSONL 不重写，首批没有 fsync、事务、崩溃后投递、自动摘要或恢复。

Console: 新增 pnpm dev:console 离线样例，只组合 FixtureWorld 与 ScriptedProvider。支持普通文本、多行编辑、取消、查询、停止/启动、退出；EOF 等待队列终态。管道与真实 PTY 均验证 set/get、多行和退出，PTY Ctrl+C 正常显示 stopping -> stopped 并返回 exit 0。

Verification: pnpm test 62 项通过；pnpm run typecheck 通过；pnpm run sample 通过（stopped、value=1、entries=7）。测试均未联网。新增输入闭环、容量/时限、停止/写入边界、事件监听器重入、两轮 Responses 原始项与失败工具回执、终端输入测试。使用说明见 docs/终端Console.md，项目与父目录的进度图已同步。

Open issues: M2 增量独立 Review 和负责人验收尚待进行；真实 Provider 工具往返尚未执行；首个生产 World 待确定。持久化增强与恢复范围在首批闭环验收后另行规划。M1 原有独立 Review 由负责人确认，本次自验不替代增量 Review。
