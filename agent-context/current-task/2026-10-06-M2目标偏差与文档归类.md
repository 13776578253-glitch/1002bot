# M2 目标偏差与文档归类

日期：2026-10-06。

负责人要求记录 M2 实现后围绕 Console 输入闭环产生的目标偏差，将持续运行 Agent 设计约束迁入 `scratch/Off-topic discussion/`，并核查终端 Console 文档用途与归类。

核查确认 Event 是通用 JSON 事实契约，但 World 尚无事件订阅契约；UserInput 使用 FIFO，Event 直接调用 handleEvent，两者忙状态互斥。Event 被拒绝并不自动证明最终丢失，是否丢失取决于调用方保留与重投；Runtime 不提供排队保证。legacyRuns 也不保证多个 Event 串行。

新增 [目标偏差讨论](../../scratch/Off-topic%20discussion/2026-10-06-M2目标偏差与持续运行方向.md)，记录持续世界 Agent 的定位、源码证据、统一触发调度方向与验收场景。设计约束迁至 [新位置](../../scratch/Off-topic%20discussion/持续运行Agent设计约束.md)，原要求继续有效。终端 Console 是已实现功能的操作与接口说明，迁至 [使用说明](../../docs/使用说明/终端Console.md)。同步现行文档与计划的引用；历史任务和旧草稿保留原文，历史任务另追加迁移说明。

验证方式：核对迁移文件内容、旧路径消失、新路径存在，以及调整后的 Markdown 本地链接。此次仅调整文档，不修改源码或执行运行时重构。

验证结果：迁移后的两份文件存在，旧路径已移除；检查讨论、设计约束、终端说明、M1/M2 汇报、范围计划、迁移记录与父目录入口中的 45 个本地 Markdown 链接，全部目标存在。未运行代码测试（无代码变更）。

追加归类（2026-10-06）：代码阅读与注释.md 对应现有代码，属于开发者阅读与维护指南，迁至 [docs/开发指南](../../docs/开发指南/代码阅读与注释.md)。文件正文保持原样，同步 Console、M2 汇报与父目录入口引用；历史注释任务追加迁移注记。
